The program

What you will actually learn

Not just theory. Every module ends with something you can show on your portfolio.

Web fundamentals

Understand how HTML, CSS and the browser render a page — semantics, the box model and the cascade.

Responsive interfaces

Grid, Flexbox and spacing systems that look right on a phone, a laptop and a 4K display.

Interactive UI

Navigation, cards, forms, tables, modals and dashboards — the components real products are made of.

JavaScript & APIs

DOM events, form validation, the Fetch API and proper loading and error states.

Git & teamwork

Branching, pull requests and code review so you learn to work in a real team repo.

Portfolio project

Finish with a deployed, API-connected app — a Student Management Dashboard of your own.

Roadmap

Five phases, one finished project

Each phase ends with a working deliverable you push to GitHub.

  1. Phase 01

    CSS Frameworks

    Tailwind CSS or Bootstrap, Grid & Flexbox, spacing, typography, color systems and responsive design patterns.

    01

    Deliverable

    A responsive landing page built from a Figma mock

  2. Phase 02

    UI Development

    Navigation bars, cards, forms, tables, modals, login & registration pages and dashboards.

    02

    Deliverable

    An auth screen + dashboard UI kit in your own style

  3. Phase 03

    Development Workflow

    Git & GitHub fundamentals, project folder organisation, version control, team collaboration and deployment basics.

    03

    Deliverable

    A clean repo with branches, commits and a deployed preview

  4. Phase 04

    JavaScript & APIs

    JS fundamentals, DOM manipulation, events, form validation, the Fetch API, REST integration plus loading and error states.

    04

    Deliverable

    A CRUD app backed by a public REST API

  5. Phase 05

    Final Project

    Bring it all together — plan, design, build and deploy a practical front-end project such as a Student Management System.

    05

    Deliverable

    A live, shared project on your portfolio

Code of conduct

Rules & expectations

  • Attend scheduled sharing sessions regularly and punctually.

  • Complete assignments within the specified deadlines.

  • Participate actively in discussions and practical exercises.

  • Submit your own work — plagiarism is not allowed.

  • Inform the organisers in advance when you cannot attend a session.

Repeated absences or missed assignments may result in removal from the program.
