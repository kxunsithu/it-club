# IT Club – Front-end Development Knowledge Sharing Program

## 📌 About the Program

The **IT Club Front-end Development Knowledge Sharing Program** is designed to help junior students learn front-end development step by step, from basic web technologies to building practical user interfaces.

The program focuses on hands-on practice, collaboration, assignments, and real-world projects to help students develop their front-end development skills.

## 🎯 Objectives

* Understand the fundamentals of front-end development.
* Learn to build responsive and user-friendly interfaces.
* Practice HTML, CSS, JavaScript, and CSS frameworks.
* Develop problem-solving and teamwork skills.
* Build projects for a personal portfolio.
* Prepare for future web development projects.

## 🛠️ Technologies

* HTML5
* CSS3
* Bootstrap or Tailwind CSS
* JavaScript (Vanilla JavaScript)
* Git and GitHub
* REST APIs
* Visual Studio Code

## 📚 Learning Roadmap

### 1. CSS Frameworks

* Bootstrap or Tailwind CSS
* Grid and Flexbox
* Spacing and typography
* Colors and layouts
* Responsive design

### 2. UI Development

* Navigation bars
* Cards and forms
* Tables and modals
* Login and registration pages
* Dashboards
* Responsive web interfaces

### 3. Development Workflow

* Git and GitHub fundamentals
* Project folder organization
* Code management and version control
* Team collaboration
* Deployment basics

### 4. JavaScript and API Integration

* JavaScript fundamentals
* DOM manipulation and events
* Form validation
* Fetch API
* REST API integration
* Loading and error states

### 5. Final Project

Participants will apply their knowledge by developing a practical front-end project, such as a Student Management Dashboard or an API-connected Student Management System.

## 📋 Requirements

Participants should have:

* Basic knowledge of HTML and CSS.
* A laptop or computer for development.
* Visual Studio Code installed.
* A willingness to learn and practice.
* A commitment to completing assignments and participating in sharing sessions.

## 📏 Rules and Regulations

All participants are expected to:

* Attend scheduled sharing sessions regularly and punctually.
* Complete assignments within the specified deadlines.
* Participate actively in discussions and practical exercises.
* Respect other participants and maintain a positive learning environment.
* Follow instructions from the program organizers.
* Avoid plagiarism and submit their own work.
* Inform the organizers in advance when they cannot attend a session.

Repeated absences, failure to complete assignments, or violations of program rules may result in removal from the program according to the organizers' policies.

## 🚀 Getting Started

1. Install [Visual Studio Code](https://code.visualstudio.com/).
2. Install [Git](https://git-scm.com/).
3. Clone the project repository:
   ```
   git clone <repository-url>
   ```
4. Open the project folder in Visual Studio Code.
5. Open `<span>index.html</span>` in your browser or use the Live Server extension.
6. Start practicing and building your project.
